# DOCUMENTAÇÃO DO PROJETO

**1. Nome do projeto:**

Pedra, Papel e Tesoura.

**2. Descrição do que o projeto faz:**

O projeto consiste em um jogo digital de Pedra, Papel e Tesoura, no qual o jogador pode escolher entre três opções: pedra, papel ou tesoura. Após a escolha, o computador seleciona automaticamente uma opção aleatória. Em seguida, o sistema compara as duas jogadas e apresenta o resultado, informando se o jogador venceu, perdeu ou empatou. O objetivo é proporcionar uma experiência simples e divertida por meio de um jogo interativo.

**3. Tecnologias utilizadas:**

- **HTML:** utilizado para criar a estrutura e os elementos do jogo.
- **CSS:** utilizado para desenvolver o visual, as cores, os botões, as animações e a aparência do jogo.
- **JavaScript:** utilizado para programar as jogadas, gerar as escolhas aleatórias do computador e determinar o resultado da partida.

**4. Orientações de como executar ou visualizar o projeto:**

Para executar o projeto, é necessário colocar os três arquivos (`index.html`, `style.css` e `script.js`) na mesma pasta. Depois, basta abrir o arquivo `index.html` em um navegador, como Google Chrome ou Firefox. O jogo será exibido na tela e poderá ser utilizado normalmente, clicando nos botões Pedra, Papel ou Tesoura.
